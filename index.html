hello.kvist
(defstruct User {
  name: string
  active?: bool
})

(defn active-names [users: []User]
  (into [dynamic]string
    (comp
      (filter .active?)
      (map .name))
    users))

Get started

From source to native code.

Kvist compiles to readable Odin and imports Odin packages directly. Clone the repository and build the CLI with an installed Odin toolchain.

$ git clone https://github.com/kvist-lang/kvist.git
$ cd kvist
$ odin build src/cli/kvist
$ ./kvist run examples/language/hello.kvist
